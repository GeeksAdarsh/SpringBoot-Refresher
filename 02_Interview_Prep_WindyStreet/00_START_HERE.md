Read this file first. It tells you **what the company wants**, **what to study first**, and **in what order**.

---

## 1. The Job in Simple Words

- **Company:** Windy Street, Gurugram, hybrid. They do accounting, audit and tax work for US companies.
- **What they are building:** A software tool for **Financial Due Diligence (FDD)**.
  - A Private Equity (PE) firm wants to buy a company.
  - Before buying, accountants check that company's numbers very carefully. This is "due diligence".
  - Today they do it by hand in Excel, Word and PowerPoint, and it takes weeks.
  - Windy Street is building a web app to make it faster, using calculations, AI, and an audit trail (a record of who changed what).
- **Your job:** Build features in **React (frontend)**, **APIs (backend)**, and the **database**. Later you may move more into **backend and data work**.
- **Experience they want:** 6 to 18 months. So they expect you to talk about **real team work**: Git, PRs, code reviews, bugs you fixed, features you shipped.

## 4. How the Interview Usually Goes (for this kind of role)

1. **HR / intro call:** About you, why this company, notice period, salary.
2. **Technical round 1:** JS, React, APIs, SQL questions + your project in depth.
3. **Coding / live task:** Small problem (array/string) or a small React/API task. Sometimes a take-home.
4. **Technical round 2 / Tech lead:** Design a small feature, debugging, how you work in a team.
5. **Final / leadership:** Culture fit, learning attitude, long-term interest.

---

## 5. 5 Things That Get You Shortlisted

1. **Explain your project end to end clearly.** Button click → API → database → response. (You already have this in `01_SpringBoot_Notes/PROJECT_FLOW.md`.)
2. **Show real team work.** Talk about Git branches, PRs, code reviews, bugs, sprints.
3. **Show you are happy to learn backend and data.** The JD says this many times. Say it clearly.
4. **Know a little accounting language.** General ledger, mapping accounts, reconciliation.
5. **Communicate simply.** Small team, you talk to leaders directly. Speak clearly and calmly.
